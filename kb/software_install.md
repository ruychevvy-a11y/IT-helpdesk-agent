## 问题
- 装软件提示需要管理员权限
- 想装 Docker 做本地联调，怎么申请
- 公司有没有正版的设计软件

## 环境
- 公司电脑没有管理员权限，不能自行安装软件

## 解决步骤
1. 在开始菜单搜索「软件中心」，常用软件可以直接安装。
2. 软件中心没有的，让 IT 助手建服务请求工单，写上软件名、版本和用途。
3. 收费软件需要你的直属经理同意采购。
4. 不要安装来路不明或破解的软件。

## 原因
- 禁止自行安装软件，是为了防止恶意软件和盗版带来的风险。
