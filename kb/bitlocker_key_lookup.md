## 问题
- 员工电脑开机要恢复密钥，IT 去哪里查
- 能不能在聊天里把恢复密钥发给员工
- 后台查不到恢复密钥怎么办

## 环境
- 适用于 IT 管理员；公司笔记本的恢复密钥保存在设备管理后台

## 解决步骤
1. 先核实身份：员工本人到 IT 部出示工牌，或者按通讯录登记的号码回拨。
2. 让员工念出屏幕上的恢复密钥 ID。
3. 在设备管理后台按恢复密钥 ID 查到对应的恢复密钥。
4. 当面或电话告诉员工，不通过邮件或聊天发送。
5. 在工单里记录核验方式；后台查不到密钥的，转 IT 负责人处理。
