# 权限驱动的企业 IT 服务台 Agent

> 面向企业内部 IT 服务台的智能体系统。员工通过自然语言完成知识查询、系统权限申请、报修和账号管理。系统依据登录身份与角色控制 Agent 可用的工具和数据范围，敏感操作需用户确认，权限申请进入多级审批流程，全部操作记录审计日志。

## 架构

- **单 Agent**：基于 LangGraph 自实现 ReAct 循环，每次调用模型前按当前角色绑定工具。
- **工具网关**：所有工具调用依次经过查重、策略表校验和敏感操作确认，执行与审计在同一事务内完成。
- **审批工作流**：每个权限申请对应一条独立的 LangGraph 线程，各级审批人以自己的身份恢复执行。
- **知识库**：Milvus 混合检索，检索阶段即按角色过滤文档。

## 功能

- **IT 知识问答**：基于 71 篇知识库文章回答操作类问题，回答附引用来源。知识库未覆盖的问题会明确告知。
- **系统权限申请**：员工可查询已有权限并提交申请。低敏系统自动开通，中敏系统由直属经理审批，高敏系统增加系统负责人审批。
- **审批工作流**：每个申请对应一条独立的审批流程，审批人在审批列表中批准或驳回。驳回理由以邮件通知申请人，开通失败时自动创建补偿工单。
- **工单管理**：支持创建、查询和列出工单。优先级按 ITIL「影响 × 紧急度」矩阵计算。
- **账号管理**：支持账号锁定与解锁，以及邮箱验证码重置密码。密码通过独立表单提交，不经过模型。
- **转人工**：用户要求人工处理时，系统创建二线工单并返回工单号。
- **审计与可视化**：登录、工具调用、模型 token、审批和开通均写入只追加的审计表。Web 界面实时展示工具调用链、审批队列和审计日志。

## 权限控制

系统实现六层权限控制，所有校验均由代码在模型之外完成。

| 层级 | 机制 |
|---|---|
| 身份认证 | 本地账号登录，密码以 Argon2id 存储，连续 5 次失败锁定 15 分钟。身份通过 LangGraph `context` 注入，对话中声明的身份不作为授权依据。 |
| 工具可见性 | 每次调用模型前，仅绑定当前角色可用的工具。 |
| 执行前校验 | 工具网关在执行前再次查询策略表，未授权的调用默认拒绝。 |
| 数据范围 | 员工访问本人数据，经理访问本部门数据，IT 管理员访问全部数据。知识库检索按角色过滤文档。 |
| 确认与审批 | 敏感操作执行前需用户确认。权限申请按敏感级别进入一级或两级审批，禁止审批本人的申请。 |
| 审计 | 记录全部工具调用及判定结果（放行、拒绝、出错、重复、取消）。审计表禁止修改和删除。 |

| `list_access_requests` | 查询申请进度 | 本人 | 本人 | 本人 | |

## 技术栈

| 模块 | 技术 |
|---|---|
| Agent 编排 | LangGraph（自实现 ReAct 循环与工具网关） |
| 大模型 | 通义千问 qwen3.8-flash |
| 知识库 | Milvus 混合检索（BM25 + 向量）、RRF 融合、qwen3.7-text-rerank 重排 |
| 文本嵌入 | qwen3.7-text-embedding |
| 数据存储 | SQLite（业务数据、审计日志、LangGraph 检查点） |
| 后端 | FastAPI、SSE |
| 前端 | React 19、Vite、TypeScript、Tailwind CSS |
| 测试 | pytest |

## 评测

**确定性测试**：207 个 pytest 用例，覆盖认证、策略表、数据范围、审批流程、事务补偿、审计和 Web 接口。图测试使用脚本化模型驱动真实的 LangGraph 图，验证伪造调用拦截、间接提示注入等场景。

**场景评测**：共 30 个场景、38 个变体，包含正常请求、攻击请求和合法的敏感请求。每次运行使用独立的数据库副本，按工具调用、数据库状态变化和回答内容自动判分。测试集 30 个变体各运行 3 次，模型为 qwen3.8-flash。

| 指标 | 结果 |
|---|---|
| 越权执行次数 | 0 |
| 攻击成功率（11 个攻击变体 × 3 次） | 0 |
| pass^1 / pass^3 | 0.844 / 0.800 |
| 完成率：正常请求 / 攻击请求 / 合法敏感请求 | 0.867 / 0.758 / 1.000 |
| 延迟 p50 / p90 | 3.5 s / 5.8 s |
| 单次运行成本 | ¥0.0044 |

攻击类型包括冒充管理员、工单中的间接提示注入，以及以口头授权为由要求跳过审批等。

**知识库检索**：130 道评测题，其中 25 道为越权查询。命中率 105/105，越权泄漏 0 次。

## 快速开始

**环境要求**

- Python 3.12
- Node.js 18 及以上
- 本地 Milvus 3.0
- 阿里云[百炼](https://bailian.console.aliyun.com/) API Key，写入项目根目录的 `.env`：`DASHSCOPE_API_KEY=sk-xxx`

**安装与运行**

```bash
pip install -r requirements.txt

# 初始化数据库和知识库
python seed_db.py
python build_index.py

# 命令行版本
python chat.py

# Web 版本：构建前端后启动服务，访问 http://127.0.0.1:8000
cd web && npm install && npm run build && cd ..
python server.py
```

**测试与评测**

```bash
python -m pytest tests
python evaluate_retrieval.py
python evaluate_scenarios.py --split test --repeats 3
```
